# Проверка Java-песочницы

Эта папка предназначена только для подготовки задания. Всё внутри `participant/` отправляется участнику, поэтому результаты проверки храните снаружи.

## Автоматическая проверка

Из корня репозитория:

```bash
mvn -f review-tasks/1b-testcase-review/participant/sandbox/pom.xml -Dsandbox.build.directory=/private/tmp/best-qa-1b-build package
java -Defr.port=18081 -Defr.today=2026-11-05 -jar /private/tmp/best-qa-1b-build/manual-review-sandbox-1.0.jar
```

В другом терминале:

```bash
python3 review-tasks/1b-testcase-review/jury/verify/sandbox_check.py
```

Скрипт сбрасывает данные перед каждой проверкой и проходит правильную ветку каждого из двадцати кейсов. Он проверяет поведение приложения по BIQ; намеренно неверные шаги и ожидания исходной выгрузки не воспроизводит как требования к приложению.

`sandbox_browser_check.js` — функция для инструмента Playwright `browser_run_code` (аргумент `filename`), с шестью браузерными регрессиями: пустое уполномоченное лицо после печати, отмена закрытия, дата окончания, доступность полей подготовки, остаток счёта и сообщение после подтверждения создания. Перед повтором восстановите данные скриптом API либо перезапуском сервера. Требуются исходные учебные клиенты.

## Результат проверки 30.10.2026

- Сборка исполняемого JAR; 23 Java-теста: 21 доменный и 2 HTTP, без ошибок и пропусков.
- Приёмка API: 20/20 правильных веток.
- Браузерные регрессии: 6/6 после воспроизведения обнаруженных проблем и исправлений.
- Дополнительно в браузере пройдены открытие вклада с печатной вкладкой и исполнением; электронное закрытие с переходом к СМС и обратно; несовершеннолетний с поиском представителя и бумажным подписанием; создание с финмониторингом и записью в истории; предыдущий паспорт; переход к самосертификации и сохранение FATCA.
- Выполнено независимое ревью. Подтверждённые замечания к интерфейсу устранены и проверены регрессиями.

Проверка выполнена на Java 21 с компиляцией `--release 17`, Maven 3.10 и браузере Chromium. Самостоятельный прогон на JDK 17 и пользовательском ВДИ отдельно не выполнялся. Формула недосрочной выплаты срочного вклада остаётся явно неподдерживаемой: её нет в BIQ. Реальные банковские интеграции заменены учебными данными.

При подготовке архива проверьте физическое содержимое `participant/`: там не должно быть результатов сборки, временных файлов, кешей или материалов жюри. Исходники приложения, его Java-тесты, pom и README входят в приложение участника.
