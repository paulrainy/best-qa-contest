# Песочница ЕФР для задания 1b

Учебное приложение на Java для ручного прохождения операций из трёх BIQ: открытие вклада, закрытие счёта/вклада и создание клиента. Доступны вход, поиск, продуктовый профиль и формы операций.

Приложение исполняет правила BIQ. Тест-кейсы в `../testcases.xlsx` намеренно содержат ошибки: неверные ожидания не должны становиться поведением приложения. Оценивается таблица замечаний к кейсам. Требования остаются единственным источником истины.

## Запуск

Нужны JDK 17 или новее и Maven. Первый запуск загружает библиотеки из Maven Central; после загрузки внешние сервисы приложению не нужны.

Из этой папки:

```bash
mvn compile exec:java
```

Откройте **http://localhost:18081/efr/**. Остановка — Ctrl+C в терминале.

Если порт занят:

```bash
mvn compile exec:java -Defr.port=18082
```

Тогда адрес — `http://localhost:18082/efr/`. Приложение слушает только локальный интерфейс.

Можно собрать исполняемый JAR:

```bash
mvn package
java -jar target/manual-review-sandbox-1.0.jar
```

Для JAR параметры Java задаются до `-jar`:

```bash
java -Defr.port=18082 -Defr.today=2026-11-05 -jar target/manual-review-sandbox-1.0.jar
```

## Начальные данные и подготовка

В приложении уже есть учебные клиенты, счета и вклады с паспортами и номерами из материалов. Например:

| Паспорт | Учебный клиент |
| --- | --- |
| `4511 220345` | Петров Олег Иванович |
| `4518 990112` | Орлова Ирина Ивановна |
| `4521 223445` | Михайлова Татьяна Ивановна |

Полный список доступен в **«Тестовые данные» → «Исходные клиенты»**. Состояние клиента и его продуктов проверяйте в профиле перед каждой проверкой.

В разделе **«Тестовые данные»** можно:

- создать клиента или изменить его FATCA, ДБО, дату рождения, паспорт и историю паспортов;
- добавить текущий/карточный счёт либо вклад с выбранными суммой, валютой, статусом и датой открытия;
- изменить сумму, статус и дату открытия существующего продукта;
- задать принадлежность человека к одному из двух списков финмониторинга по паспорту.

Подготовка данных — отдельная учебная возможность. Она не заменяет банковские операции и сама не дополняет пропущенные предусловия кейса. Если для проверки нужны другие данные, подготовьте их явно. Изменение исходного объекта может повлиять на следующую проверку; для чистого состояния используйте сброс.

Дата операции по умолчанию — дата запуска приложения. Она показана в интерфейсе. Для воспроизводимой даты:

```bash
mvn compile exec:java -Defr.today=2026-11-05
```

Дата не меняется в течение работы процесса. Возрастные границы и даты исходных вкладов «30/73 дня назад» рассчитываются относительно неё.

## Подписание и контролёр

Бумажное подписание требует уполномоченное лицо банка и нажатие **«Печать»**. Печатная форма открывается в отдельной вкладке. Если браузер блокирует всплывающие окна, разрешите их для localhost.

Электронное подписание отправляет код на **учебный телефон**: нажмите **«Отправить код»**, откройте **«СМС»** в верхнем меню, прочитайте код и вернитесь в заявку по ссылке из сообщения. Реальные СМС не отправляются. Всего три попытки; повторная отправка кода не возвращает потраченные попытки.

Заявки, требующие контроля, видны пользователю `tst_contr01` в **«Задачи» → «Все задачи»**. Найдите клиента, нажмите **«Взять и исполнить»**, затем подтвердите либо отклоните/отмените операцию. Для отрицательного решения обязателен комментарий. Контролёр другого филиала не видит эти заявки.

## Сброс и ограничения

**«Тестовые данные» → «Сбросить данные»** с подтверждением удаляет учебные изменения, заявки, СМС и сессии. Потребуется войти заново. Перезапуск приложения также восстанавливает начальные данные. На диск бизнес-данные не сохраняются.

- Реальные ЕФР, АБС, ДБО, финмониторинг и принтер не подключаются: результаты соответствующих действий моделируются локально.
- BIQ-90102 задаёт формулу досрочного закрытия. Формула выплаты срочного вклада в день окончания срока и позже не определена; такой расчёт приложение явно отклоняет с объяснением. Досрочное закрытие и «До востребования» поддерживаются.
- BIQ не описывает процесс открытия текущего счёта. Кнопка «Открыть счёт» из предупреждения ведёт в подготовку учебных данных.
- Подготовку данных нельзя применять посреди исполняемой заявки: если условия продукта изменились, начните операцию заново.
- Исходный дефектный кейс может быть невыполним или давать другой результат; это не основание менять правила BIQ.

## Проверка сборки

```bash
mvn test
```

Тесты проверяют бизнес-границы, права, подписание, создание клиентов и настоящий локальный HTTP-сервер. Для HTTP-проверок среда должна разрешать открытие локального порта.
