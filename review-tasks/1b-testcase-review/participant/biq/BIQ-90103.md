# BIQ-90103 Создание клиента: проверка на дубль и по спискам финмониторинга

| Поле | Значение |
| --- | --- |
| Тип | Доработка |
| Статус | Готово к тестированию |
| Система | ЕФР |
| Автор | Д. Корнеев, аналитик |

## Описание

При создании клиента по паспорту РФ ЕФР проверяет, нет ли уже карточки этого человека: сначала по паспорту, затем по ФИО и дате рождения. Затем клиента проверяют по спискам финмониторинга. Если дубль исключить нельзя, создание подтверждает контролёр.

## Роли и права

| Роль | Что может в операции |
| --- | --- |
| Клиентский менеджер ТП | Создать клиента |
| Менеджер-операционист ТП | Создать клиента |
| Финансовый консультант ТП | Нет доступа: кнопка «Создать клиента» не отображается |
| Контролёр ТП | Подтвердить или отменить создание в разделе «Задачи». Создать клиента не может |

## Бизнес-правила

### П1. Анкета и возраст

- **П1.1.** Операция запускается кнопкой «Создать клиента» на странице «Поиск клиента». Состав анкеты — в разделе «Состав форм». Кнопка «Отмена» в анкете закрывает её без сохранения, карточка не создаётся, пользователь возвращается на страницу «Поиск клиента».
- **П1.2.** Клиенту на дату создания должно быть не меньше 14 лет. В день 14-летия создать клиента уже можно. Если клиент младше, после «Сохранить» выводится сообщение С1, карточка не создаётся.
- **П1.3.** Проверки П2–П4 выполняются после нажатия «Сохранить» в анкете, в том порядке, в котором они описаны.

### П2. Дубль по паспорту

- **П2.1.** Если в ЕФР уже есть клиент с теми же серией и номером паспорта РФ, выводится сообщение С2 с кнопкой «Открыть карточку». Новая карточка не создаётся, дальнейшие проверки не выполняются.

### П3. Дубль по ФИО и дате рождения

- **П3.1.** Если клиента с таким паспортом нет, но есть клиент с теми же фамилией, именем, отчеством и датой рождения, открывается окно «Обратите внимание» с сообщением С3. В окне кнопки «Ввести данные предыдущего паспорта» и «Нет предыдущего паспорта».
- **П3.2.** ФИО сравниваются без учёта регистра, буквы «Е» и «Ё» считаются одинаковыми. Отчество участвует в сравнении: если у одного клиента отчество есть, а у другого нет, ФИО не совпадают.
- **П3.3.** «Ввести данные предыдущего паспорта» открывает поля «Серия» (4 цифры) и «Номер» (6 цифр) и кнопку «Проверить».
  - Предыдущий паспорт совпадает с текущим или одним из прежних паспортов найденного клиента — это тот же человек. Выводится сообщение С4 с кнопкой «Открыть карточку», новая карточка не создаётся.
  - Не совпадает — проверка на дубль пройдена, выполняется П4.
- **П3.4.** «Нет предыдущего паспорта» — проверка на дубль не пройдена, но создание продолжается с подтверждением контролёром (П5). Выполняется П4.

### П4. Проверка по спискам финмониторинга

- **П4.1.** Клиент проверяется по спискам «Перечень организаций и физических лиц, причастных к экстремизму или терроризму» и «Решения межведомственной комиссии».
- **П4.2.** При совпадении открывается окно «Обратите внимание» с сообщением С5 и кнопкой «Продолжить». Операция продолжается, сведения о совпадении ЕФР автоматически передаёт в финмониторинг. В истории операций карточки появляется запись «Передано в финмониторинг».
- **П4.3.** Само по себе совпадение со списком не требует подтверждения контролёром.

### П5. Сохранение и подтверждение

- **П5.1.** Если проверки П2–П4 пройдены и не было П3.4, карточка сохраняется сразу и выводится сообщение С6. Клиент получает статус «Активен».
- **П5.2.** В случае П3.4 выводится сообщение С7. Заявка на создание получает статус «На подтверждении» и уходит в раздел «Задачи» контролёра ТП того же филиала. Карточка до подтверждения имеет статус «Черновик» и в поиске не находится.
- **П5.3.** Контролёр открывает заявку кнопкой «Взять и исполнить». На форме в блоке «Внимание» выводится С8 и данные найденного клиента-двойника (ФИО, дата рождения, паспорт). Доступны кнопки «Подтвердить операцию» и «Отменить операцию».
- **П5.4.** После «Подтвердить операцию» выводится С6, клиент получает статус «Активен». После «Отменить операцию» обязательна причина в поле «Комментарий», заявка получает статус «Отменена», карточка удаляется.

## Состав форм

**Анкета «Создание клиента»:**

- «Фамилия», «Имя» — обязательные;
- «Отчество» — необязательное;
- «Дата рождения», «Пол» — обязательные;
- «Гражданство» — РФ, только чтение;
- паспорт РФ: «Серия» (4 цифры), «Номер» (6 цифр), «Дата выдачи», «Код подразделения», «Кем выдан» — обязательные;
- «Мобильный телефон», «Адрес регистрации» — обязательные.

Кнопки «Сохранить» и «Отмена».
