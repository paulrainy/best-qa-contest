# BIQ-90102 Закрытие счёта и вклада: остаток, способ подписания, законный представитель

## Описание

Операции «Закрытие счёта» и «Закрытие вклада» проверяют остаток и счёт для перечисления средств. Способ подписания выбирается по доступу клиента в ДБО. Для несовершеннолетнего клиента нужен законный представитель. При бумажном подписании закрытие вклада подтверждает контролёр.

## Роли и права

| Роль | Закрытие счёта | Закрытие вклада |
| --- | --- | --- |
| Менеджер-операционист ТП | Да | Да |
| Финансовый консультант ТП | Нет: пункт «Закрыть счёт» не отображается | Да |
| Клиентский менеджер ТП | Нет | Нет |
| Контролёр ТП | Нет, только подтверждение в разделе «Задачи» | Нет, только подтверждение в разделе «Задачи» |

## Бизнес-правила

### П1. Запуск операции

- **П1.1.** Операция запускается из детальной информации продукта: кнопка «Показать» напротив продукта, затем «Операции», затем «Закрыть счёт» или «Закрыть вклад».
- **П1.2.** Операция доступна только для продукта в статусе «Открыт».

### П2. Закрытие счёта

- **П2.1.** Закрыть можно только текущий счёт. Для карточного счёта пункт «Закрыть счёт» не отображается.
- **П2.2.** Остаток на счёте должен быть равен 0,00 ₽. Иначе выводится сообщение С1, операция не начинается.
- **П2.3.** При нулевом остатке открывается форма «Закрытие счёта». После подписания заявка получает статус «Исполнена», счёт — статус «Закрыт». Контролёр закрытие счёта не подтверждает, при любом способе подписания.

### П3. Закрытие вклада

- **П3.1.** Поле «Счёт для перечисления» обязательное: в списке открытые текущие рублёвые счета клиента. Если такого счёта нет, выводится сообщение С2 с кнопками «Открыть счёт» и «Отмена», операция не продолжается.
- **П3.2.** Если вклад закрывается раньше даты окончания срока, на форме выводится сообщение С3. Поле «Сумма к выплате» показывает сумму с процентами, пересчитанными по ставке досрочного расторжения. Поле только для чтения.
- **П3.3.** У вклада «До востребования» нет срока, поэтому его закрытие не считается досрочным и сообщение С3 не выводится.
- **П3.4.** После исполнения заявки сумма к выплате зачисляется на выбранный счёт, вклад получает статус «Закрыт».

### П4. Способ подписания

- **П4.1.** Электронное подписание доступно, только если у клиента подключено ДБО с уровнем доступа «Полный». На форме тогда выбран способ «Электронное», его можно сменить на «Бумажное».
- **П4.2.** Если ДБО не подключено или уровень доступа «Ограниченный», при выборе операции выводится сообщение С4 с кнопками «Продолжить с бумажным подписанием» и «Отмена».
- **П4.3.** Электронное подписание:
  - кнопка «Отправить код» отправляет клиенту СМС;
  - менеджер вводит код в поле «Код из СМС» (6 цифр) и нажимает «Подписать»;
  - при неверном коде выводится С5, всего три попытки;
  - после третьего неверного кода выводится С6, заявка получает статус «Отменена».
- **П4.4.** Бумажное подписание: обязательное поле «Уполномоченное лицо банка», кнопки «Печать» и «Документы подписаны». Кнопка «Документы подписаны» активна только после «Печать».

### П5. Несовершеннолетний клиент

- **П5.1.** Клиент младше 18 лет на дату операции — несовершеннолетний. В день 18-летия клиент уже совершеннолетний.
- **П5.2.** Для несовершеннолетнего на форме выводится сообщение С7 и обязательный блок «Законный представитель». Представитель ищется по серии и номеру паспорта среди клиентов Банка. Пока он не выбран, кнопка «Далее» неактивна.
- **П5.3.** Для несовершеннолетнего подписание только бумажное, независимо от доступа в ДБО. Сообщение С4 при этом не выводится.

### П6. Подтверждение контролёром

- **П6.1.** Закрытие вклада с бумажным подписанием после «Документы подписаны» получает статус «На подтверждении» и уходит в раздел «Задачи» контролёра ТП того же филиала. Выводится сообщение С8.
- **П6.2.** Закрытие вклада с электронным подписанием контролёр не подтверждает: после верного кода заявка сразу получает статус «Исполнена».
- **П6.3.** Контролёр открывает заявку кнопкой «Взять и исполнить», доступны «Подтвердить» и «Отклонить». После «Подтвердить» заявка исполняется по П3.4. После «Отклонить» обязательна причина в поле «Комментарий», заявка получает статус «Отклонена», вклад остаётся в статусе «Открыт».

## Состав форм

**«Закрытие счёта»:** номер счёта и остаток (только чтение), способ подписания, поля и кнопки подписания по П4.

**«Закрытие вклада»:**

- номер вклада, вид вклада, дата окончания срока (только чтение);
- «Сумма к выплате», только чтение;
- «Счёт для перечисления», обязательное;
- блок «Законный представитель» — по П5.2;
- способ подписания, поля и кнопки подписания по П4.

Кнопки «Далее» и «Отмена».
