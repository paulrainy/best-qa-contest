# Черновик ключа 1д: API и БД (TK900301–TK900310)

Черновик для сборки ключа в задаче 8. Строки — в окончательном формате ключа. Номера ловушек старые (Л2, Л3, Л5, Л7, Л9, Л10), задача 8 перенумерует.

Файлы тестов: `participant/python/tests/api/` — `agreements/` (TK900301, TK900302, TK900308), `auth/` (TK900310), `orders/` (TK900303–TK900305), `tariffs/` (TK900309), `tax_reports/` (TK900306, TK900307). Исправленные версии — в `jury/fixed/python/tests/api/` с той же структурой папок.

Общий код (`tests/conftest.py`, `invest/steps/clients.py`, `invest/db/invest_db.py`) теперь без дефектов. Прежние Д1–Д10 переехали в тесты или исправлены: учётка бэк-офиса — из `Config.user('backoffice')`, фикстура `client` удаляет только своего клиента, `create_client` без изменяемого значения по умолчанию, в `InvestDb` нет запросов-дефектов, у `wait_order_status` и `wait_tax_report_status` — сообщение и пауза между попытками.

## Верные замечания вне ключа

Баллов не дают, не штрафуются.

- TK900301: тариф проверяется по ответу на создание клиента, а не в БД.
