# Просмотр сценариев JMeter — памятка жюри

Только для жюри. В архив участника памятку не включать.

1. Откройте Apache JMeter **5.6.3**: в `../participant/1-scripts/` дважды нажмите `open-jmeter.bat` на Windows x64 или `open-jmeter.command` на Mac с Apple Silicon. Java включена в комплект. Если macOS блокирует запуск скачанного файла, разрешите его в «Системные настройки → Конфиденциальность и безопасность» согласно правилам вашего компьютера.
2. Выберите **File → Open** и откройте нужный `.jmx` из `../participant/1-scripts/`.
3. Слева находится дерево сценария. Раскрывайте узлы и выбирайте элементы: справа отображаются их настройки. В полях с длинным текстом и кодом используйте прокрутку.
4. Чтобы найти место из замечания участника или ключа, пройдите по указанному пути в дереве. `Test Plan` — корень, остальные пути в ответах начинаются с элемента под ним.
5. Просматривайте настройки и сопоставляйте замечание с `answer-key.md`. Методика участника находится в `../participant/methodology.md`. При необходимости исправленный сценарий можно отдельно открыть из `fixed/scripts/`.
6. Для следующего сценария снова используйте **File → Open**. Если случайно изменили настройки, закройте план без сохранения.

**Кнопку Start (зелёный треугольник) нажимать не нужно.** Задание проверяется просмотром; стенда нет. Не сохраняйте изменения поверх материалов участника.

CSV с данными находятся в `../participant/1-scripts/data/` и просматриваются отдельно текстовым редактором или Excel.

Справка: [запуск JMeter](https://jmeter.apache.org/usermanual/get-started.html), [работа с планом](https://jmeter.apache.org/usermanual/build-test-plan.html).
