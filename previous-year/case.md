# Кейс для конкурса «Лучший тестировщик»: выжимка

Выжимка из документа «Кейс для конкурса Лучший тестировщик_fin». Это условие кейса для участника.

## Кейс «Логика кредитного скоринга (Black Box Decision)»

**Легенда.** Банк внедряет «Кредитный Конвейер» — модуль, который сам принимает решение по кредиту. Логика решения скрыта в хранимой процедуре `SP_GET_CREDIT_DECISION`. На вход она получает параметры заёмщика, на выходе выдаёт вердикт.

## Входные параметры

| Параметр | Значения |
|---|---|
| Age (возраст) | 18–100 лет |
| Income (доход) | 0–1 000 000 руб. |
| CreditHistory (кредитная история) | `GOOD`, `BAD`, `EMPTY` |
| Employment (тип занятости) | `EMPLOYED`, `UNEMPLOYED`, `SELF_EMPLOYED` |

## Бизнес-правила (ТЗ от аналитиков)

1. Возраст < 21 — отказ. Исключение: возраст 18–20, доход > 50 000 и занятость `EMPLOYED` — одобрено.
2. Кредитная история `BAD` — отказ всегда.
3. Занятость `UNEMPLOYED` — отказ всегда.
4. Во всех остальных случаях — одобрено.
