# IntelliJ IDEA: навигация, конфигурация и Runtime Debug: выжимка

Выжимка из документа «IntelliJ IDEA Навигация, конфигурация, Runtime Debug_KEA». Вводный модуль для инженеров НТ. Учебные проекты: `uc01_cdigetxref_2_0` (JMeter-скрипт как Maven-проект) и `ImageMerger` (простое Java-приложение). В оригинале 25 скриншотов.

## Интерфейс

- **Основные зоны:**
  - Navigation bar;
  - Project tool window (дерево проекта);
  - Editor;
  - всплывающие и контекстные меню;
  - Status bar;
  - Tool window bars (боковые полосы с инструментами);
  - Toolbar;
  - Gutter (номера строк, точки останова, кнопки запуска).
- **Виджеты Toolbar:** Main menu (Windows и Linux), Project (переключение проектов), VCS (текущая ветка, переключение), Run (конфигурации запуска и отладки).
- **Панель Maven** (значок «M» справа). Большинство проектов ЦК НТ — Maven, и любую фазу или цель запускают двойным кликом.

## Дерево проекта

Открыть проект через Main menu → Open. Expand All и Collapse All; двойной клик открывает файл. Новый файл или папку создают через контекстное меню (New → File или Directory, остальное — шаблоны), удаляют через Delete.

## Поиск

| Инструмент | Вызов (Windows / macOS) | Что ищет |
|---|---|---|
| Search Everywhere | Navigate → Search Everywhere (двойной Shift) | Классы, файлы, символы, действия, настройки по имени. Вкладки All, Classes, Files, Symbols, Actions, Text |
| Поиск в файле | Ctrl+F / Cmd+F; замена Ctrl+R / Cmd+R | Строки с учётом регистра, целых слов, regex |
| Поиск по проекту | Ctrl+Shift+F / Cmd+Shift+F | Строки с фильтрами и Scope (только открытые файлы, модули, пользовательская область) |
| Подсветка использований | Каретка на символе | Использования символа в текущем файле |
| Find Usages | Alt+F7 / Option+F7 | Все использования символа по проекту, а не текст |
| Расширенный Find Usages | Ctrl+Alt+Shift+F7 / Cmd+Option+Shift+F7 | То же с настройкой Scope |

## Запуск и отладка

- **Запуск:** зелёная стрелка в Gutter у main-класса → «Run '….main()'». Лог появляется внизу.
- **Отладка:**
  - поставить точки останова кликом в Gutter;
  - «Debug '….main()'»;
  - на точке останова видны потоки и значения переменных;
  - Resume — до следующей точки, красный квадрат — остановить.

## Замечание

Модуль назван «Runtime Debug», но охватывает только базовый локальный запуск с точками останова. Для инженера НТ важнее то, чего в нём нет:

- Step Over, Step Into;
- Evaluate Expression;
- условные точки останова;
- удалённая отладка — подключение к работающей JVM на стенде (Remote JVM Debug).

## Что полезно для конкурса

Материал инструментальный, для конкурсных заданий почти бесполезен. Пригодится разве что знание, что участники из НТ привыкли к IDEA и Maven-проектам. Это стоит учитывать при выборе формы песочниц.
