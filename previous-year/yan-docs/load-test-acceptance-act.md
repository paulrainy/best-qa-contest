# Акт сдачи-приёмки НТ: выжимка

Выжимка из документа «Акт сдачи-приемки НТ_KEA». Это учебный модуль о том, как инженер НТ составляет акт сдачи-приёмки работ по бизнес-инициативе (БИ) на нагрузочное тестирование.

## Что это за документ

- Акт НТ фиксирует выполненные работы по нагрузочному тестированию релиза в рамках задачи BIQ.
- Без него нельзя закрыть BIQ. Он же служит основанием для ввода доработок ИС/ППО в эксплуатацию в сроки, заданные Планом.
- Акт составляют после согласования протокола НТ, в последнюю неделю месяца. Отвечает за него инженер НТ.
- Формат задан шаблоном из приложения к ВНД о порядке разработки и доработки ПО. Готовый акт прикладывают в СУЖЦ ПО/СКАП.

## Как заполнять

| Поле | Что указать |
|---|---|
| Шапка | Текущую дату |
| Наименование ПО | Тестируемую систему, как она названа в БИ на НТ (например, «КХД.CDI») |
| № и дата БИ | Полное название БИ, например «BIQ-34652 „Проведение нагрузочных испытаний системы КХД.CDI релиза март 2026“» |
| Краткое описание работы | Перечень работ: проверка нагрузочной станции и заглушки, актуализация инструментов, прогон тестов по методике, анализ узких мест, контрольный прогон после исправлений, формирование протокола НТ |
| Приёмочное тестирование | Фиксированный текст: «Приемо-сдаточные испытания не проводились. Демонстрация функционала не осуществлялась.» |
| Заключение | Фиксированный текст: «Работы выполнены в полном объеме в соответствии с поставленной задачей.» |
| Приложение | Протокол НТ со всеми его приложениями и лист согласования протокола, с числом листов у каждого |
| Место размещения конфигурации ИС/ППО | Не заполняется |
| Плановые сроки | Только фактическую дату установки релиза в ПРОМ, в формате дд/мм/гггг |
| Подписанты | По перечню для конкретной системы со страницы из сопроводительных материалов. Актуальные должности смотрят в СЭД |

## После заполнения

Акт со всеми приложениями загружают в СЭД и отправляют на согласование. Процесс описан в модуле «Согласование протокола/акта НТ и заявки на доступ к СР и СТ в СЭД». Согласующие те же, что и подписанты в акте.

## Что полезно для конкурса

- Акт почти целиком состоит из шаблонных формулировок. Проверять по нему можно только аккуратность: верный номер BIQ, полный перечень приложений, формат даты, нужные подписанты.
- Логичная последовательность в этом процессе: протокол НТ → его согласование → акт → согласование акта → закрытие BIQ.
