# Должностная инструкция инженера ЦК автоматизации тестирования: выжимка

Выжимка из документа «2023_ДИ АТ Инженер.doc» (PDF из 4 страниц, скан без текстового слоя). Это типовая инструкция 2023 года: должность «Инженер», роль «Разработчик АТ», ЦК автоматизации тестирования Блока обеспечения и контроля качества выпуска изменений ПО ООО «РСХБ-Интех».

## Требования к кандидату и подчинение

- Высшее образование и стаж по специальности не менее 6 месяцев.
- Подчиняется руководителю центра.

## Должен знать (профессиональная часть)

Пункты 3.1–3.15 — общие ЛНА, тот же набор, что у инженера НТ. Профессиональные:

- классификация видов и типов тестирования, техники тест-дизайна и комбинаторика тестов;
- архитектура тестируемых систем, интеграции с внешними системами;
- жизненный цикл ПО; жизненный цикл, типы, классификация и статистика дефектов;
- формат предоставления информации по регламентам Общества;
- Java и основы ООП;
- GitLab: репозитории, клонирование, ветвление, слияние;
- тестирование API и фреймворки вроде RestAssured;
- GUI-тестирование на Selenium WebDriver и принципы веб-автоматизации;
- фреймворки Cucumber, JUnit, TestNG;
- основы SQL-запросов.

## Должен уметь

- разрабатывать и поддерживать автотесты по требованиям и спецификациям;
- работать с инструментами для разработки и выполнения сценариев, планов, протоколов;
- понимать процессы, цели и среды применения продукта;
- взаимодействовать с разработчиками, аналитиками и технологами;
- запускать и отлаживать тесты, анализировать результаты, делать отчёты;
- взаимодействовать с ручными тестировщиками.

## Обязанности

- анализ документации по доработкам;
- контроль качества и анализ ошибок, которые могут возникнуть у конечных пользователей;
- запрос недостающей информации у аналитиков;
- учёт времени на выполнение сценариев и сохранение результатов в хранилище тестовой документации;
- проверка результатов на соответствие и оформление по формату подразделения;
- выяснение причин ошибок вместе с разработкой;
- управление устранением дефектов по стандартам;
- консультации смежных подразделений;
- отчёты по работе, времени и дефектам;
- стандартный блок: поручения, внутренний контроль, конфиденциальность, антикоррупция, персональные данные.

## Права и ответственность

Права и ответственность стандартные, как у инженера НТ. Права:

- принимать решения в пределах компетенции;
- вносить предложения руководителю;
- повышать квалификацию;
- запрашивать информацию;
- обеспечивать условия труда;
- визировать документы;
- взаимодействовать со сторонними организациями;
- пользоваться интернетом.

Замещает его инженер, ведущий или главный инженер по распоряжению руководителя.

## Что полезно для конкурса

- Стек из инструкции (Java, Selenium, RestAssured, JUnit или TestNG, Cucumber, SQL, GitLab) совпадает с выбранным для задания 1а: Java + Selenide (обёртка над Selenium WebDriver) и TestNG, плюс Java + SQL. Это прямое обоснование выбора стека для жюри и участников.
- В инструкции нет Playwright. Если оставлять Playwright-часть 1а, её разумно подавать как бонусную, а не обязательную. Это аргумент к открытому вопросу о весе бонуса за Playwright.
