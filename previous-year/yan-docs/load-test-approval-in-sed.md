# Согласование протокола и акта НТ и заявки на доступ к СР и СТ в СЭД: выжимка

Выжимка из документа «Согл. протокола акта НТ и заявки на доступ к СР и СТ в СЭД_KEA». Это пошаговая инструкция по работе в системе электронного документооборота (СЭД). В оригинале 40 скриншотов интерфейса, здесь только суть шагов.

## 1. Подготовка: плагин СЭД в Яндекс Браузере (VDI VMware Horizon)

- Зайти в СЭД под корпоративной почтой и доменным паролем.
- Настройки → «О системе» → «Проверить плагин» у каждого компонента, в том числе File Uploader CMJ. Если рядом с плагином появилась версия, всё установлено.
- Если плагина нет: скачать его, скопировать путь к файлу (Shift + правый клик → «Копировать как путь»), запустить установщик из командной строки администратора.
- Проверить, что web-расширение СЭД установлено и включено. При необходимости поставить .crx, перетащив его на страницу расширений.
- Перезапустить браузер и ещё раз проверить все плагины.

## 2. Согласование протокола или акта НТ

1. «Создать» → «Документ произвольной формы».
2. Вкладка «Реквизиты»:
   - заголовок — название протокола или акта;
   - тип — «Технологический документ»;
   - вид — «Протокол тестирования … модификации ИС/ППО» или «Акт сдачи-приемки работ по бизнес-инициативе по автоматизации (типовая форма)»;
   - подписант — руководитель (вводить текстом, система сама подскажет);
   - дата; штрих-код кнопкой «Авто»;
   - дело «086-9-07 Документы (технологические) в электронном виде»;
   - количество листов, экземпляров и приложений.
3. Вкладка «Содержание»: добавить файлы через «Действия» → «Из файловой системы». Основной документ должен стоять первым, то есть левее всех. Одиночный файл добавляют без архива. Образцы имён:
   - «Акт по BIQ-23180», «ЛС Акта по BIQ-23180»;
   - «Приложение 1. Протокол НТ 02.2025», «Приложение 2. ЛС протокола НТ 02.2025»;
   - «Протокол НТ 19.01», где 19.01 — последний день релиза;
   - «Приложение 1. Сравнение показателей», «Приложение 2. Графики и pwr».
4. Вкладка «Доступ»: «Доступен всем». Сохранить. Можно сохранить как шаблон для следующих документов.
5. «Отправить» → «На согласование». На вкладке «Жизненный цикл» выбрать тип согласования, стадии, согласующих и параметры.

### Что делать после отправки

| Ситуация | Действие | Что с визами |
|---|---|---|
| Нужно поменять файлы | «В процессе» → «Прекратить» → «Редактировать» → заменить файлы → отправить заново | Все согласующие визируют заново |
| Нужно прекратить согласование | «В процессе» → «Прекратить» | — |
| Нужно поменять согласующих | «В процессе» → «Приостановить» → карандаш → правка → «Сохранить» → «Продолжить». Убрать можно только того, кто ещё не завизировал | Проставленные визы сохраняются |
| Согласовали с замечаниями | Исправить → «Отправить» → «На снятие замечаний» тем, кто их оставил → после согласования «Печать» → «Лист снятия замечаний» | Лист снятия замечаний прикладывают к протоколу и листу согласования в БИК |

## 3. Заявка на доступ к СР и СТ

1. Заполнить word-заявку.
2. В СЭД: «Создать» → «Документ произвольной формы», категория «Сервисные заявки». Подписант — генеральный директор. Дело «086-1-13 Сервисные заявки в Департамент информационных технологий АО „Россельхозбанк“».
3. Приложить word-заявку, отметить «Доступен всем», сохранить.
4. «Отправить» → «На согласование». Обязательные согласующие:
   - распорядитель серверов;
   - непосредственный руководитель;
   - «ДИТ-Согласование ТЕСТОВАЯ среда (АО „Россельхозбанк“)».
5. После согласования: «Жизненный цикл» → принтер → «Лист без иерархий подчинённых листов» → скачать лист согласования.
6. «Редактировать» → приложить лист согласования → «Сохранить» → «Отправить» → «На подписание».

## Что полезно для конкурса

Материал чисто процедурный, проверочных знаний тестировщика в нём почти нет. Годится разве что для вопросов на знание процесса. Например: что произойдёт с визами при прекращении согласования и что — при приостановке.
