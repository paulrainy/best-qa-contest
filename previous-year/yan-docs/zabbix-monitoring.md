# Zabbix: мониторинг и работа с метриками: выжимка

Выжимка из документа «Zabbix мониторинг и работа с метриками_KEA». Учебный модуль для инженеров НТ: что такое Zabbix, как собрать дашборд и как искать и комбинировать метрики. В оригинале 36 скриншотов.

## Что такое Zabbix

Open-source система мониторинга корпоративного класса. Собирает, хранит, анализирует и визуализирует метрики серверов, сети, ВМ, облаков, БД и приложений. В отличие от Prometheus, это решение «из коробки»: сбор, алертинг и веб-интерфейс в одном продукте.

**Компоненты:**

- **сервер** — сбор, обработка, оповещения;
- **БД** — хранение; поддерживаются MySQL, PostgreSQL, SQL Server, Oracle;
- **агент** — сбор локальных метрик, активно или по запросу сервера; по словам модуля, необязателен;
- **прокси** — предобработка и разгрузка сервера, нужен при большом парке;
- **веб-интерфейс.**

**Интерфейсы для НТ:**

- `/app` — метрики ПО;
- `/sys` — аппаратные метрики серверов;
- отдельный неподдерживаемый старый инстанс, где остались, например, серверы НТ-контура САФ ФЛ.

## Дашборды

**Свой комплексный дашборд:**

1. Dashboards → Create dashboard: имя, период по умолчанию, слайд-шоу при нескольких страницах.
2. Properties страницы.
3. Добавить виджет «Graph (classic)»: Select graph → хост-группа (группы НТ-контуров начинаются с `Load_Test/`, например `Load_Test/SAFFL NT`) → сервер → метрика → Add.
4. Добавить ещё графики и страницы (Add → Add page). Все нужные метрики окажутся в одном месте.

**Готовый дашборд.** Для `/sys` обычно есть дефолтный с базовыми аппаратными метриками: Monitoring → Hosts → фильтр по хост-группе → Dashboards в строке сервера.

## Поиск и комбинирование метрик

1. **Найти метрику:** Monitoring → Hosts → хост-группа → Latest data (можно выбрать несколько хостов). Сузить по тегам, например Application = Memory. Затем Graph и нужный интервал.
2. **Скомбинировать:** отметить чекбоксы метрик (например, Active memory и Available memory) → «Display stacked graph». Не больше 50 метрик, столько помещается на страницу. Метрики нескольких серверов комбинируют так же: добавить хосты в фильтр и отметить метрики.

## Замечания

- Пример с комбинированием неудачный. Stacked-график складывает значения, и «Active + Available memory» на нём даёт бессмысленную сумму. Для сравнения метрик на одном графике нужна кнопка «Display graph» (наложение), а не stacked.
- В модуле «корреляцией» назван обычный отбор метрик по хост-группе. Это путает с корреляцией в смысле анализа (связь метрик между собой) и с корреляцией в скриптах НТ.
