# Работа с заявками в СУИТ: выжимка

Выжимка из документа «Работа с заявками в СУИТ_KEA». Это учебный модуль о том, какие заявки в СУИТ (сервис поддержки) нужны инженеру ЦК НТ и как их заводить. Параметры заявок в оригинале даны скриншотами (их 24), здесь они переписаны текстом.

## Основные заявки

Во всех случаях работа идёт через «Каталог услуг»: тип, категория, группа и сама услуга.

| Задача | Как заводить | Доступные услуги |
|---|---|---|
| Работа с тестовой БД | Группа услуги — тип СУБД стенда, например PostgreSQL | Внесение изменений; восстановление работоспособности после остановки; восстановление логического объекта или Full Backup; дамп; изменение объекта под SuperUser; рестарт инстанса; UPDATE и UPGRADE СУБД; VACUUM FULL; настройка кластера; выдача конфигов, логов и отчётов о работе СУБД; проверка работоспособности; «Другое» |
| Учётные записи в СР и СТ (среды разработки и тестирования) | Базовая ИТ-услуга → «Инфраструктурные сервисы СР и СТ» → «Сопровождение учетных записей СР и СТ» | Сброс пароля; предоставление прав доступа; «Другое» |
| Мониторинг Zabbix | Базовая ИТ-услуга → «Техническая поддержка Системы мониторинга Zabbix» → «Сопровождение…» | Консультация; внесение изменений (например, добавить хосты в группу или подключить метрики); устранение ошибок в работе мониторинга |
| Частное облако | Базовая ИТ-услуга → «Управление вычислительными ресурсами (Частное облако)» → «Технические вопросы по Частному облаку» | Добавление и удаление администраторов РП; перенос ВМ между РП; добавление существующих серверов в РП; установка ППО; ошибка; консультация |
| Установка, обновление и изменение конфигурации ПО на серверах | Заводит только пользователь с ролью «Распорядитель сервера» | — |

**Типовой пример заявки по БД:** «Сбор pwr — приложите PWR-отчёты с сервера … за период с … по …». Исполнитель (вторая линия СУБД PostgreSQL) прикладывает HTML-отчёт в чат заявки.

**Без доступа к СУИТ** заявку можно оформить через чат поддержки ЦОС или письмом на адрес 8888. Она автоматически появится в СУИТ, и дальше с ней работают там.

## Полезные функции

- **Шаблоны.** После заполнения полей нажать «Использовать как шаблон». Шаблон сохраняется в «Мои услуги» → «Все шаблоны», откуда его можно поправить и отправить.
- **Повторная подача.** «Мои заявки» → «Завершённые» → нужная заявка → «Повторная подача».
- **Поиск обращений.** Если непонятно, как сформулировать запрос, можно найти похожие заявки по ключевым словам или номеру и посмотреть, как их составили.

## Что полезно для конкурса

Материал процедурный, внутренний для ЦК НТ. Для заданий из него полезен только контекст: PWR-отчёты по БД получают заявкой во вторую линию СУБД, а не сами. Это стоит учитывать, если в задании по НТ появится сбор артефактов.
