# Инструмент визуализации метрик Grafana: выжимка

Выжимка из документа «Инструмент визуализации метрик Grafana_KEA». Учебный модуль для инженеров НТ: папки, дашборды, панели, переменные, ссылки и откат версий. В оригинале 67 скриншотов. Запросы к Prometheus и InfluxDB даны только скриншотами, здесь они переписаны текстом.

## Что такое Grafana

OSS-инструмент для запросов, визуализации, алертинга и исследования метрик, логов и трейсов из любых источников. Источники подключаются плагинами: Prometheus, CloudWatch, Loki, Elasticsearch, PostgreSQL, GitHub и др. Для НТ это основной инструмент визуализации результатов: RPS, 95-й перцентиль времени отклика и процент ошибок на одном дашборде.

В ЦК НТ две Grafana:

- локальная, её поддерживает ЦК НТ;
- общая, её поддерживают системные администраторы. Интерфейсы немного различаются из-за версий.

## Основные операции

| Операция | Как |
|---|---|
| Папка | Dashboards → Manage → New folder. Нужна, чтобы группировать дашборды одной системы |
| Дашборд | Dashboards → Manage → New Dashboard. В настройках (шестерёнка): имя, описание, папка, теги для поиска |
| Панель | Add panel → Add an empty panel → Data source → запрос → Title → Apply, затем Save дашборда |
| Группа панелей (row) | Add panel → Add a new row → шестерёнка → Title. Группы сворачиваются, по большому дашборду проще ходить |
| Ссылки между дашбордами | Settings → Links → Add dashboard link. Опции: Include current time range, Include current template variable values (если имена переменных совпадают), Open in new tab |
| Откат | Settings → Versions → выбрать версию → Restore. При сохранении пишут комментарий «для историчности» |

## Источники данных в панелях

- **InfluxDB (метрики JMeter).** Конструктор в стиле SQL:
  - `FROM` — база и measurement `jmeter`;
  - `SELECT` — `value` и функция (`mean`, `count`);
  - `WHERE` — например `testName = 'my_test'`;
  - `GROUP BY time($__interval)`.

  Пример табличной панели «Шаги сценариев»:
  ```sql
  SELECT sum("count") AS all_count FROM "$database"."$retention_policy"."$measurement_name"
  WHERE $timeFilter AND statut = 'all' AND transaction =~ /^__$scriptNum[K]*\d*_.+/ GROUP BY transaction
  -- err_count: то же с statut = 'ko'; avg_time: mean("avg") с statut = 'ok'
  ```
- **Zabbix.** Поля Group, Host, Item tag, Item заполняют по тем же значениям, что в Zabbix: хост-группа, сервер, тег и метрика. Метрики с одинаковыми параметрами быстро добавлять копированием запроса с заменой только Item.
- **Prometheus (метрики JMeter).** Пример табличной панели по операциям:
  ```promql
  # count за выбранный интервал
  sum( max_over_time(jmeter_requests{requestName=~".+XX.+", testName="$project", runId="$runId"}[${__range_s}s])
     - min_over_time(jmeter_requests{…}[${__range_s}s]) ) by (requestName)
  # avg = прирост суммы времени / прирост числа запросов
  ```
- **Mixed.** Запросы к разным источникам в одной панели.

## Настройка отображения

- **Тип панели.** Time series, Table и др.
- **Legend mode.** Например, таблица.
- **Legend values.** Total, Current, Min, Max, Avg, Count. Decimals — это не статистика, а число знаков после запятой.

## Переменные

Нужны, чтобы не делать отдельный дашборд под каждый тест: `testName`, `runId`, `environment`, `host`.

- **Custom.** Значения перечисляют через запятую, например два хоста.
- **Query.** Значения берут из источника. Пример: все хосты Zabbix-группы, подходящие под regex `.*_java`.
- **Multi-value** и **Include All** — множественный выбор и вариант «все».
- В панели вместо захардкоженного имени хоста пишут `$host`.

## Замечания

- В примере InfluxDB среднее время считается как `mean("avg")`, то есть среднее средних по интервалам. Если число запросов в интервалах разное, результат искажён. Правильнее делить сумму времени на сумму количества, как это сделано в Prometheus-примере.
- На скриншоте Prometheus-таблицы у ряда операций 95-й перцентиль меньше среднего (например, Avg 176 ms при 95pct 139 ms). Это возможно только при очень тяжёлом хвосте, а чаще говорит о том, что перцентиль посчитан некорректно, например как среднее перцентилей по интервалам. Модуль на это внимания не обращает.

## Что полезно для конкурса

Отличный материал для задания трека НТ «найди ошибку в дашборде или отчёте». Например:

- среднее средних;
- перцентиль меньше среднего;
- stacked-график памяти (см. [zabbix-monitoring.md](zabbix-monitoring.md));
- ссылка между дашбордами без «Include current time range», из-за которой сравнивают разные интервалы.
