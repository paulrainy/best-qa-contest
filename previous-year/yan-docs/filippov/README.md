## Что полезно для конкурса

Новое в папке — только тесты. Они показывают, как в компании сейчас проверяют знания после обучения: закрытые вопросы с одним правильным ответом из четырёх, проверяется запоминание процедуры. Это образец формата, который может проверять неэксперт по ключу, и одновременно набор типичных ошибок такого формата. Подробнее — в выжимках тестов.
