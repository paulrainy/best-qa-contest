# Тест «Работа с заявками в СУИТ»: выжимка

Выжимка из документа «Тест Работа с заявками в СУИТ_KEA». Это тест из 10 вопросов к модулю о заявках в СУИТ (см. [suit-requests.md](../suit-requests.md)). В каждом вопросе четыре варианта ответа, правильные выделены в оригинале жёлтым.

## Вопросы и ключ

| № | Вопрос | Правильный ответ | Дистракторы |
|---|---|---|---|
| 1 | Что происходит с заявкой, отправленной письмом на адрес 8888 | Автоматически дублируется в СУИТ | Дублируется по запросу в письме; только при высоком приоритете; нужна для эскалации |
| 2 | Поддерживается ли в СУИТ работа с Частным облаком (ЧО) | Да: добавление серверов в ЧО, консультации, устранение неполадок | Нет, в App.Farm; нет, в СЭД; да, но только консультации |
| 3 | Кто может заводить заявки на изменение конфигурации ПО на серверах | Роль «Распорядитель сервера» | Любая роль; «Менеджер ИТ-сервиса»; инженер тестируемой системы |
| 4 | Можно ли повторно подать заявку | Да, для любой заявки | Только для отклонённой; нельзя; только под другой ролью |
| 5 | Есть ли в СУИТ поиск обращений | Да, по ключевым словам или номерам заявок | В «Маршрутной карте»; только свои обращения; поиска нет |
| 6 | Можно ли создавать и использовать шаблоны заявок | **Два ответа:** кнопка «Использовать как шаблон» при заведении заявки; использование через «Мои услуги» → «Все шаблоны» | Кнопка «Создать шаблон»; шаблонов нет |
| 7 | Какой «Тип ИТ-услуги» выбрать для заявки по мониторингу Zabbix | Базовая ИТ-услуга | ИТ-услуга, обеспечивающая процессы Банка; «Внесение изменений по системе мониторинга Zabbix»; бизнес-услуга |
| 8 | В каком поле указать услугу в заявке на работу с БД | «Услуга» | «Тип ИТ-услуги»; «Техническая операция»; «ИТ-услуга» |
| 9 | Какие услуги доступны в заявке по учётной записи в СР и СТ | **Три ответа:** сброс пароля; предоставление прав доступа; «Другое» | Удаление учётной записи |
| 10 | Что происходит с заявкой, созданной в чате поддержки ЦОС | Автоматически дублируется в СУИТ | Дублируется по запросу; только высокий приоритет; только для эскалации |

## Замечания

- **Вопросы с несколькими правильными ответами не помечены.** В вопросах 6 и 9 верны два и три варианта, в остальных — один. По формулировке это не различить, поэтому участник, выбравший один вариант в вопросе 6, ответит неполно.
- **Вопросы 1 и 10 дублируют друг друга.** Это один факт из модуля («заявки через ЦОС и письмом на 8888 автоматически дублируются в СУИТ»), разбитый на два вопроса с одинаковыми дистракторами.
- **Вопрос 4 спорный.** В модуле повторная подача показана только из раздела «Мои заявки» → «Завершённые». Ответ «для любой заявки» шире того, что сказано в модуле: про заявки в работе там ничего нет.
- В вопросе 7 дистрактор «Внесение изменений по системе мониторинга Zabbix» — это название реальной услуги внутри той же ветки каталога. Он проверяет, знает ли участник, на каком уровне каталога что выбирается. Это удачный дистрактор.

## Что полезно для конкурса

Как и тест по СЭД, по содержанию для конкурса не нужен. По форме это ещё один антипример закрытых вопросов: в ключе с фиксированными ответами нужно явно помечать вопросы с множественным выбором и заранее решить, как считать частично верный ответ. Иначе проверка по ключу перестаёт быть однозначной.
