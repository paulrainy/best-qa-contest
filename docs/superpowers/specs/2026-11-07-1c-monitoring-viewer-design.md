# Автономный просмотр мониторинга 1c

Пользователь выбрал автономный `review.html` и поручил продумать и сразу реализовать его. Участник открывает файл из распакованного архива в браузере; установка, сеть, сервер и Grafana не нужны.

## Подходы

- Grafana с плагином Zabbix требует доставки дополнительного ПО и не даёт графиков без источников данных; отклонён из-за сложности доставки.
- PDF прост в открытии, но неудобен для длинных запросов и поиска настроек.
- Выбран HTML: навигация по пяти заданиям, конфигурация панелей и переменных, исходники, поиск и копирование в одном файле.

## Устройство

Генератор `review-tasks/tools/build_monitoring_viewer.py` использует только стандартную библиотеку Python. Читает строго пять файлов участника 16–20 и шаблон HTML/CSS/JS из `jury/source/monitoring/viewer/`. Все ресурсы встраиваются в результат. Команда `--check` сравнивает результат с сохранённым файлом, ничего не записывает и возвращает ненулевой код для устаревшего HTML.

Слева — пять заданий, сверху — поиск по всем исходникам. Для JSON доступны «Панели», «Переменные», «Настройки», «Исходник». Панели раскрываются по названию и ID; запросы и все остальные свойства отображаются с исходными именами ключей. Неизвестные свойства также видны, отсутствующие значения не заменяются выдуманными умолчаниями. Переменные показываются вместе с исходными regex и настройками выбора. Для SQL — подсветка синтаксиса и исходные номера строк. Поиск возвращает строки с переходом к исходнику, копирование сохраняет исходный текст. При недоступном буфере обмена текст можно выделить и скопировать вручную.

HTML экранирует содержимое исходников. Скрипт не загружает соседние файлы через fetch: работает по `file://`, даже если HTML скопировали отдельно. Оригинальные файлы доступны рядом и остаются авторитетным материалом; HTML является снимком на момент сборки. Без JavaScript исходные данные доступны в последовательном документе.

## Границы и проверка

Нет выполнения запросов, графиков, редактирования, проверки ответов, подсказок из ключа, зависимостей из CDN. Исходные пять заданий, ключ и исправленные версии не меняются. Интерфейс и инструкции на русском. В архив участника не попадают исходники генератора.

Проверки: точность встроенного текста и номеров строк, полнота настроек, HTML-экранирование, отсутствие внешних ресурсов и данных жюри, повторяемость сборки и `--check`; браузерная проверка локального файла, навигации, поиска, копирования и узкого окна; общий pytest генераторов. Корпоративные ограничения браузера на конкретной VDI остаются отдельной проверкой.
