# Monitoring Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Просмотр пяти заданий мониторинга из одного автономного HTML.

**Architecture:** Python заранее строит все представления из файлов участника, встраивает CSS, JavaScript и исходные тексты. JavaScript переключает представления, ищет строки и копирует текст без сетевых запросов.

**Tech Stack:** Python standard library, HTML, CSS, JavaScript; существующий pytest для тестов.

**Spec:** `docs/superpowers/specs/2026-11-07-1c-monitoring-viewer-design.md`.

## Global Constraints

- Установка, сеть, сервер и Grafana не нужны.
- Исходные пять заданий, ключ и исправленные версии не меняются.
- Интерфейс и инструкции на русском.
- Все свойства и исходные тексты сохраняются; нет интерпретации настроек через предполагаемые умолчания.

## Review Focus

- Строки с HTML и закрывающим script не превращаются в исполняемый код.
- False, null, пустые строки и массивы не пропадают из настроек.
- Поиск и копирование работают при file:// и не теряют исходную нумерацию.
- Нет доступа к сети и содержимому жюри.
- Длинные запросы доступны на узком экране и с клавиатуры.
