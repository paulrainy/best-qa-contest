# Исправление лишних ошибок протоколов 1c

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Устранить ошибки подготовки протоколов из аудита, сохранив 25 учебных дефектов и 10 ловушек задания.

**Architecture:** Править Python/Markdown-исходники, собирать PNG, DOCX и XLSX штатными генераторами. Общие графики серверов формировать из тех же метрик, что и таблицы. Итоговый p95 стабильности задаётся отдельным синтетическим измерением отчёта JMeter, без агрегирования оконных p95.

**Tech Stack:** Существующие Python, NumPy, Matplotlib, python-docx, openpyxl, pytest.

**Spec:** аудит протоколов от 05.11.2026 (`review-tasks/1c-load-review/jury/protocol-review-2026-11-05.md`; файл в репозиторий не добавлен), пункты дополнительных проблем 1–6; пользователь поручил исправить найденные ошибки.

## Review Focus

- Новые графики не должны исправить задуманные дефекты или вводить шестой.

- CPU и память ОС измеряются в диапазоне 0–100 %, heap показан отдельно.
- Все серверы приложений, адаптеров, БД и генераторов представлены по CPU и памяти, для БД есть диск.
- Ключ не должен выдавать гипотезу о причине за доказанный факт или смешивать интервалы 14.
