# Java-песочница 1b — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Отдельная запускаемая Java-песочница с интерфейсом по трём BIQ задания 1b.

**Architecture:** Maven-проект в `participant/sandbox`, Java-домен с состоянием в памяти, JDK HttpServer с JSON API и статический браузерный интерфейс. Сценарии приёмки жюри хранятся вне папки участника; загрузка приложения не зависит от жюри или 1a.

**Tech Stack:** Java 17, Maven, Jackson, JUnit, HTML/CSS/JavaScript без сборщика.

**Spec:** `docs/superpowers/specs/2026-10-30-1b-java-sandbox-design.md`

## Global Constraints

- Три BIQ — источник бизнес-правил; исходные дефектные кейсы и ключи не менять.
- Java 17+, локальный порт 18081 с `efr.port`, единая дата с `efr.today`.
- Русские интерфейс, сообщения и документация; точные сообщения BIQ.
- Данные только в памяти, явная подготовка и сброс, четыре роли и ограничение задач филиалом.
- Не добавлять внешние интеграции, БД, Docker и Node.js; не менять 1a/1c.
- Недосрочная выплата срочного вклада вне определённых BIQ расчётов, с явным объяснением.

## Review Focus

- Прямой HTTP-вызов не обходит право роли, принадлежность продукта клиенту или ограничения филиала.
- Повторное подтверждение и повторное подписание не создают второй продукт и не зачисляют деньги дважды.
- Некорректные суммы, даты и паспорта дают понятную ошибку; ведущие нули паспорта сохраняются.
- Отмена, шаг назад и обновление страницы не теряют утверждённые данные и не исполняют операцию.
- Сброс удаляет сессии, заявки и SMS и восстанавливает воспроизводимые относительные даты.

## Файлы и интерфейсы

Корень проекта `review-tasks/1b-testcase-review/participant/sandbox/`:

- `pom.xml`, `.gitignore`, `README.md`: самостоятельная сборка, запуск Maven и исполняемый JAR.
- `src/main/java/ru/rshb/playground/manual/Model.java`: типы пользователей, клиентов, продуктов и операций.
- `Messages.java`: тексты BIQ и денежное форматирование.
- `SandboxStore.java`: хранение, роли, подготовка, поиск, операции и переходы.
- `SeedData.java`: исходные данные из явно заданных предусловий, относительные даты.
- `SandboxServer.java`: HTTP, сессии, JSON, статические ресурсы, запуск и остановка.
- `src/main/resources/efr/{index.html,app.css,app.js}`: интерфейс в стиле 1a.
- `src/test/java/ru/rshb/playground/manual/{SandboxStoreTest,SandboxServerTest}.java`: требования BIQ и HTTP.
- `review-tasks/1b-testcase-review/jury/verify/sandbox_check.py`: правильные ветки всех 20 кейсов через API, без распространения с участником.

Доменный интерфейс: `SandboxStore(LocalDate today)`, `User authenticate(String login, String password)`, `Map<String,Object> dispatch(User user, String action, Map<String,Object> input)`, `void reset()`. Все изменяющие операции внутри синхронизированного dispatch, денежные значения BigDecimal, даты LocalDate. Ответы содержат сериализуемые снимки, а не живые изменяемые объекты.

HTTP: POST `/efr/api/login`, POST `/efr/api/action` с `{action, ...input}` и Bearer-токеном, GET `/efr/api/session`, POST `/efr/api/reset`; статика `/efr/`. Действия: bootstrap/search/client/prepare/operation/open-deposit/begin-close/update-operation/print/send-sms/sign/tasks/take/decide/create-client/continue-client/set-fatca/sms. Разрешения проверяются в домене, не в HTML.
