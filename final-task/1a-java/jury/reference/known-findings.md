# Состояние проверок F10/F16

Намеренные дефекты удалены. F10 требует комиссии 100,00 после 90 000,00 + 20 000,00; F16 — возврата 40 400,00 и восстановления остатка после FAILED. Обе проверки входят в полный зелёный набор, без known_issue, skip/xfail и разрешённых падений.

Текущие прогоны и хеш — в [отчёте](report.md). Прежние факты сохранены в [историческом отчёте](evidence/before-defect-removal-report.md) и не описывают новую сборку.

Два отдельных замечания аудита ещё требуют проверки/исправления вне снятия намеренных дефектов: уведомления неизвестного клиента возвращают 200 вместо договорного 404; правило трёх неудачных обработок до DLQ не единообразно для потребителей. F01–F18 не исчерпывают контракт; зелёный набор не считается доказательством отсутствия любых ошибок.
