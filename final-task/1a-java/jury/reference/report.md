# Отчёт Java-эталона

Дата: 10.11.2026. Проверяемый контракт — версия 2.0. Шкала баллов не разрабатывалась.

## Окружение и сборка

macOS 27.2, ARM64, Apple M4 Max, 36 GiB RAM. Maven 3.10.0. Стенд собран на Temurin JDK 17.0.21+9, compiler release 17. Проверены JDK 17.0.21 и Homebrew JDK 21.0.13.0.3. SHA-256 готового `transfer-stand.jar`: `73c7773c0c029702e781f3dfd3e625046e5e69866dd1def82f71c47511113ecf`. Полный состав зависимостей и исходников — [манифест](../../../jury/stand-manifest.md).

Все четыре физических копии проверены на обеих JVM: HTTP, AMQP publish/read, H2 JDBC и PostgreSQL SELECT/запрет записи, H2/Qpid/Dojo веб-консоли, reset, метрики, стандартная история30 000. Процессы стендов выполнялись под sandbox-exec: исходящая сеть запрещена, кроме localhost. Отдельный вызов connect к внешнему IP завершился PermissionError. Сборка во время этих запусков не выполнялась. [Матрица8 запусков](evidence/runtime-matrix.json), [проверка запрета внешней сети](evidence/network-denied-ip.log).

В 47 JAR нет нативных DLL/SO/dylib; максимальный major базовых class-файлов61 (Java17), multi-release записи рассматриваются JVM отдельно. Это поддерживает переносимость байткода между ARM64/AMD64, но не подменяет проверку Windows/ВДИ.

## Вывод и ограничения

Два денежных отклонения [F10/F16](known-findings.md) требуют исправления продукта и повторного полного прогона перед выпуском. Текущий ожидаемо красный полный набор является корректным эталоном по ТЗ. Зелёный контрольный набор показывает работоспособность остальной части, но не снимает эти два дефекта.

Windows/ВДИ не проверен: необходим отдельный запуск и пилот на целевом окружении. Короткая диагностика ограничения учёта не заменяет полный нагрузочный эталон и не доказывает НФТ. Ручной, нагрузочный и Python-эталоны будут выполняться по своим согласованным планам; шкала — после всех четырёх.

## Независимая выдача и диагностика

В локальном независимом клоне включён `core.autocrlf=true`, установлены фильтры `git lfs install --local`, получены объекты `git lfs pull --include=final-task/**`. Проверка дистрибутива подтвердила реальные бинарники и SHA-256. Стенд Java17 запущен из клона с PATH без Maven и запретом внешней сети; подключения, контроли и F10/F16 подтверждены. [Лог запуска и проверок](evidence/clone-offline.log), [целостность](evidence/clone-distribution.log).

Короткая диагностика Н1 на той же сборке: 600/600 запросов приняты за 10 с при60 POST/с, ошибок/503 нет, p95 принятого POST5,18мс, очередь после поступлений303,18,67% принятых завершены за2с. Все дождались финала при дренировании. [Сводка](evidence/n1-diagnostic.json), [исходные записи](evidence/n1-diagnostic.jsonl). Это диагностический прогон на ноутбуке без прогрева, не подтверждающий профиль НФТ и не готовый нагрузочный эталон.

Архивы каждого participant проверяются по точному составу и байтам; jury, исходники, эталоны, кеши и данные запуска исключены. Итог проверки — [archive-checks.json](evidence/archive-checks.json).

## Независимая приёмка

Другой исполнитель повторил запуск по README в чистом клоне и с пустым локальным Maven-кэшем. Java17 и21: полный61/2 известных/0errors/0skip, анализатор0; контроль59/0/0/0. [Ревью](evidence/independent-review/review.md), [состав прогонов](evidence/independent-review/replay-summary.json).

На отдельной копии исходников внесена контрольная ошибка: получателю зачислялась лишняя0,01 ₽. Неизменённый обычный тест F02 обнаружил разницу1 000 100,01 вместо1 000 100,00; после восстановления исходника и на исходном JAR тот же тест прошёл. Бинарники participant не менялись. Отдельный полный прогон с недоступным JDBC дал39 ошибок подключения при сохранённых двух KNOWN assertions — анализатор вернул1. После восстановления соединения контроль59 снова зелёный. [Восстановление и чистота клона](evidence/independent-review/restoration.json).

Ревью: Critical0, Important0. Замечание к устаревшему статусу дизайн-документа закрыто обновлением метаданных приёмки. Windows/ВДИ и остальные эталоны не объявлены готовыми. Все процессы проверки остановлены.

## Решения при исполнении

- Русские этапы плана выполнялись по их полному тексту; служебный извлекатель английских Task-заголовков заменён чтением этих разделов. Объём работ сохранён.
- Отчёты Surefire очищаются на initialize, чтобы частичный прогон не использовал старые XML; цена — дополнительный закреплённый Maven clean-plugin3.3.2 при первой установке.
- Сырые XML и логи Maven с пробелами внутри stacktrace сохранены без исправления; проверка whitespace отключена только для этих файлов доказательств, исходники проверяются обычно.
- Ручной, нагрузочный и Python-эталоны не входят в приёмку первого плана. Следующим пользователь разрешил ручной. Windows/ВДИ остаётся отдельным обязательным пилотом до официальной выдачи; без него переносимость этого окружения не подтверждена.

Ветки стабильных Python сверены с [Python Developer’s Guide](https://devguide.python.org/versions/); проверялись конкретные интерпретаторы из матрицы, будущие версии требуют повторной проверки.
