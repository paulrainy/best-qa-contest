## Границы, оставленные независимым ревью

Каждый пункт рассмотрен исполнителем и оставлен с указанной причиной:

- Нагрузка/НФТ/пороги ВДИ — пользователь отложил нагрузочный план. Цена: выполнение НФТ пока не доказано.
- Windows/ВДИ AMD64 и другие ОС — доступна только macOS ARM64. Цена: перед выдачей нужен целевой пилот.
- Повторная доставка, три попытки/DLQ, «ядовитые» сообщения, гонки и восстановление — общий дизайн исключает их из базового F01–F18. Цена: соответствующий риск надёжности остаётся непроверенным.
- Серверный запрет UPDATE и реализация стенда — ранее проверенная основа с тем же хешем. Python использует SELECT и не правит продукт. Цена: этот этап не повторяет отдельную серверную проверку записи.
- Все10 комбинаций не повторяются независимым исполнителем — он проверил новую установку3.11/Java21, два полных прогона и все авторские XML/хеши. Цена: остальные комбинации имеют авторские runtime-доказательства.
- Будущие версии, все patch-релизы и произвольные зависимости — открытая верхняя граница не заменяет фактическую матрицу. Цена: после релизов нужны новые проверки.
- Внешняя доставка GitHub/LFS и полностью пустой общий uv-кэш — проверены локальный origin, новая `.venv` и реальные LFS-байты. Цена: внешняя доставка проверяется при выпуске.
- Шкала, веса и завершение всех четырёх направлений — отдельный этап после оставшегося нагрузочного эталона. Цена: текущая работа ещё не даёт готовую балльную шкалу.

Открытых мелких замечаний этого ревью не оставлено. M1 исправлен автором с контролем чувствительности и всей зелёной матрицей; повторного независимого ревью усиленного64-case состава не было. Слияние и публикация в этот план не входят; ветка сохранена для дальнейшей работы.
