# Каркас автотестов на Java

Maven-проект с JUnit 5, RestAssured, клиентом RabbitMQ (`amqp-client`), драйвером H2 и AssertJ. Библиотеки скачиваются в папку проекта (`.m2/`), в общий репозиторий Maven ничего не пишется.

```
mvn test
```

Стенд должен быть запущен. Адреса — в `src/test/resources/stand.properties`.

- `Stand` — подключения к API, брокеру и БД и помощник для чтения событий из брокера.
- `SmokeTest` — пример: перевод между своими счетами, событие `TransferCreated`, проводки в БД.

Каркас — только отправная точка. Структуру, библиотеки и подход выбираете сами.
