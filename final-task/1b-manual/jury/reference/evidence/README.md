# Формат и навигация доказательств

- `Mxx*.jsonl`: явные запросы/ответы основного кейса; буквенные/числовые суффиксы — варианты, `data` — подготовка/общая сверка.
- `C01-*.jsonl`: возврат глобальных настроек и новый контрольный OWN.
- `R-*.jsonl`: повтор обычных карточек в другом порядке на новых данных без reset.
- `EX*.jsonl`: исследовательские действия, наблюдения и очистка.
- `SQL*.txt`: сырой вывод читающего H2-клиента; `SQLC*` — явно синтетические read-only контроли.
- `M01*.png`: вход в H2/Qpid на Java17 и21; `M01*-sql.txt` — история30000.
- `*-metrics.txt`: снимки очередей в намеренно приостановленных состояниях.
- `java*-version.txt`, `os.txt`, `stand-sha256.txt`: фактическая среда и идентификация сборки.

JSONL сохраняет время, HTTP-метод/путь, тело запроса, ключ, код curl, длительность, заголовки, сырой ответ и ошибку клиента. Денежные значения в сырой строке ответа сохраняют исходное представление. Доказательства не вычисляют PASS/FAIL: сравнение с ожидаемым сделано в кейсах и отчёте.
