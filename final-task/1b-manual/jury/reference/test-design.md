# Тест-дизайн

Техники выбраны по правилам продукта, до заполнения фактических результатов. Полные кейсы — [test-cases.md](test-cases.md).

| Правило | Техника и набор | Почему это достаточно для основной проверки |
| --- | --- | --- |
| Сумма 10–300000, максимум 2 знака | Границы 9,99/10/300000/300000,01; точность 10,001; OWN исключает дневной лимит | Соседние стороны обоих ограничений и лишний знак — M04 |
| Обязательные поля/формат | Классы: нет поля, короткий/числовой счёт, строка вместо суммы, невалидный JSON, неизвестный счёт, отсутствующий/длинный ключ | Различаем валидацию 400, сущность 404 и недостаток денег 422 — M05 |
| Статусы счетов | Таблица решений 3×3 для OTHER и OWN: ACTIVE→ACTIVE/BLOCKED разрешено, любая CLOSED запрещена, BLOCKED не списывает | Два разрешённых и семь запрещённых сочетаний каждого типа — M06 |
| Самоперевод | Отдельный запрещённый класс, даже при ACTIVE и достаточных деньгах | Не смешивается с неверным счётом — M07 |
| Дневной лимит 150000 | Границы 149999,99/150000/150000,01 на трёх независимых клиентах; бесплатный порог исчерпан предыдущим днём. Накопление в тех же сутках: 100000 + 50000,00/50000,01, первый перевод COMPLETED или PROCESSING | Отсутствует влияние пересечения порога комиссии; лимит учитывает уже занятую сумму и PROCESSING — M08 |
| Календарные сутки/месяц | Переход 23:59→00:01 МСК; последнее число месяца→первое | Дневное и месячное использование сбрасываются отдельно — M09,M11 |
| Комиссия | Бесплатно 100000; пересечение 90000+20000; после порога 10→30, 3456,78→34,57 и точная половина 3000,50→30,01; верхняя граница 150000→1500 в M08 | Бесплатный класс, только сверхпороговая часть, минимум, округление и максимум — M03,M08,M10,M11 |
| Идемпотентность | Тот же ключ и числовое значение 100/100,00; другое тело; другой клиент; до/после 24 ч | Различаем возврат исходной операции 200, конфликт 409 и новую 202 — M12,M13 |
| Асинхронный жизненный цикл | PROCESSING при паузе; resume→COMPLETED; закрытие получателя до resume→FAILED | Статус, деньги, проводки и уведомление наблюдаются независимо — M14–M17 |
| Оборот | COMPLETED выбранной даты завершения; перевод создан накануне; FAILED/PROCESSING и соседний день | Проверяется выборка, не только сумма случайной истории — M18 |

M01 — контроль среды. Исследовательские сессии EX01/EX02 проверяют последовательности действий и восстановление, которые не исчерпываются отдельными граничными значениями. Нагрузочные процентили и промышленная отказоустойчивость здесь не оцениваются.
